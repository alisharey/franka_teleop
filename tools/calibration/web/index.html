Programming mode in Desk, guide the arm, let go, then Snapshot (or press Space).
  1. Desk: FCI active, Programming mode. Keep the tag and the cameras where they are.
  2. Guide the arm so the wrist camera sees the tag (20–50 cm away), let go, wait until "Arm still", Snapshot.
  3. Repeat 15–25 times, tilting the gripper 20–40° about different axes between snapshots (not just sliding it).
  4. Calibrate. Check that the drawn end-effector axes sit on the real gripper in the check images.
